## 🚀 Método Mais Rápido (5 minutos)

### Pré-requisito

-   Instale o Node.js: https://nodejs.org (se ainda não tiver)

### Passos

1. **Extraia o arquivo ZIP** `controle-pressao-app-deploy.zip`

2. **Abra o terminal/prompt** na pasta `controle-pressao-app`

3. **Execute estes comandos:**

```bash
# Instalar Railway CLI
npm install -g @railway/cli

# Fazer login (abrirá o navegador)
railway login

# Inicializar projeto
railway init

# Fazer deploy
railway up

# Gerar URL pública
railway domain

# Abrir aplicação
railway open
```

**Pronto! Sua aplicação estará rodando permanentemente! 🎉**
